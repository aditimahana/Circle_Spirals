# Circle Spirals

A collection of three Python Turtle graphics exercises that create spiral patterns using circles and different turning angles. Each variation produces a unique geometric design by changing the angle of rotation.

## Files

| File | Description |
|---|---|
| `CircleSpiral1.py` | Creates a winding circular spiral using a 91-degree turn. |
| `CircleSpiral2.py` | Creates a circular spiral using a 90-degree turn. |
| `CircleSpiral3.py` | Creates a different geometric pattern using a 60-degree turn. |

## Concepts Learned
- Importing and using the `turtle` module
- Creating and controlling a Turtle pen
- Using `for` loops and `range()`
- Drawing circles with `circle()`
- Experimenting with angles and rotations
- Understanding how small code changes affect visual patterns

## How to Run
1. Make sure Python is installed.
2. Run any of the three `.py` files.
3. Observe how changing the turning angle affects the resulting pattern.

## Key Differences
All three programs use `t.circle(x)` to draw increasingly larger circles.

The main difference is the turning angle:
- **91°:** Creates a winding, slightly irregular spiral.
- **90°:** Produces a right-angle-based circular pattern.
- **60°:** Creates a more tightly repeating geometric pattern.

## Experiment
Try changing the turning angle in each program and observe how the resulting designs change!
